# Panaderia
App gratuita (Android / iOS) para llevar el inventario y las ventas de una panadería: ingreso de panes, mermas, rebajas, turnos de caja y reportes por cajero y por período.

- [PLAN.md](./PLAN.md) — plan del proyecto, factibilidad, costos, requisitos de las tiendas y cronograma.
- [DESARROLLO.md](./DESARROLLO.md) — guía técnica: arquitectura, modelo de datos, sincronización offline, donaciones y sprints.
